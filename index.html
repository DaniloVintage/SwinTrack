📖 Guía de Mantenimiento Anual (WAQ y RFEN)

1. Calendario de actualización:
• 1 de enero: Tiempos base WAQ piscina 50m (p50).
• 1 de septiembre: Tiempos base WAQ piscina 25m (p25).
• Septiembre / Octubre: Mínimas Nacionales RFEN.

2. Actualizar Tiempos Base WAQ:
Descarga los tiempos base (en segundos) en ://worldaquatics.com, edita index.html en GitHub (bloque WAQ_BASE) y pulsa Commit changes.

3. Actualizar Mínimas RFEN:
• Solo en este móvil: Súbelo arriba en «Importar JSON de Mínimas RFEN».
• Para todos los usuarios: Edita el bloque DEFAULT_RFEN_DATA en index.html de GitHub (tiempos en segundos) y pulsa Commit changes.

4. Aplicar cambios en el móvil:
Espera 1 minuto tras guardar en GitHub, abre la app y pulsa el botón 🔄 de arriba a la derecha.
